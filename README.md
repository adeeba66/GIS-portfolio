# GIS-portfolio
This portfolio includes all my GIS related projects.

1 Spatial Indices Analysis

This project presents several spatial indices derived from Landsat satellite imagery. 
These indices help analyze vegetation condition, water bodies, and moisture levels in the study area. 
All indices were generated using GIS and remote sensing techniques.

## Data used 
- Landsat satellite imagery
- Boundary shapefile
  
## Tools used 
- ArcGIS for spatial analysis and index calculation

## Indices Used

### NDVI (Normalized Difference Vegetation Index)
NDVI is used to measure vegetation health and density. 
Higher NDVI values indicate healthy vegetation, while lower values represent sparse vegetation or built-up areas.

### EVI (Enhanced Vegetation Index)
EVI improves vegetation monitoring by reducing atmospheric effects and canopy background noise.

### ARVI (Atmospherically Resistant Vegetation Index)
ARVI is designed to reduce atmospheric influences on vegetation analysis.

### GNDVI (Green Normalized Difference Vegetation Index)
GNDVI focuses on vegetation chlorophyll content and is useful for agricultural monitoring.

### NDWI (Normalized Difference Water Index)
NDWI is used to detect water bodies and analyze water content in vegetation.

### MNDWI (Modified Normalized Difference Water Index)
MNDWI improves water detection by reducing noise from built-up areas.

### SAVI (Soil Adjusted Vegetation Index)
SAVI reduces soil brightness effects when analyzing vegetation in areas with sparse vegetation.

### NDMI (Normalized Difference Moisture Index)
NDMI helps assess vegetation moisture content and drought conditions.

### MSI (Moisture Stress Index)
MSI is used to evaluate moisture stress in vegetation.

### Soil Moisture Index (SMI)
SMI is used to estimate soil moisture levels in the study area.
